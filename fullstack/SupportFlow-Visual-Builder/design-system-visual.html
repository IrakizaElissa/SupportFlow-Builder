🔗 Connectors

SVG paths with quadratic Bézier curves visualize the flow between nodes.

Property Default Active/Traversed
Stroke Color #666 (gray) #FFD700 (gold)
Stroke Width 2px 3px
Opacity 0.7 1
Animation None Dashed line flow

Connection Algorithm

Source: Bottom-center of source node

Target: Top-center of target node

Curve: Quadratic Bézier with control point midway + vertical offset

CPy = (sourceY + targetY) / 2 + Math.abs(targetY - sourceY) * 0.3

🔧 Technical Implementation

Aspect Specification
Technology Vanilla JavaScript (ES6+), CSS3, HTML5, SVG
Graph Rendering Custom implementation (NO libraries)
Connectors SVG paths with Bézier curves
Build Tools None - requires HTTP server for fetch API
External Dependencies Zero (100% custom)
Browser Support Modern browsers (Chrome, Firefox, Safari, Edge)
State Management Centralized state object with event-driven updates

File Structure

  • app.js - Main initialization & mode switching
  • graph-renderer.js - Custom graph rendering engine
  • chat-engine.js - Preview mode chat logic
  • styles.css - Complete styling
  • index.html - UI structure

Feature Implementation
